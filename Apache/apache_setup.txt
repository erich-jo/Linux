# Install Apache Web Server & FastCGI Module
sudo apt -y update && sudo apt -y upgrade
sudo apt -y install apache2 libapache2-mod-fcgid

# Verify Web Server Operation
Enter `http://localhost` into the browser; Setup successful if 'Apache2 Ubuntu Default Page' appears
Default web document location is /var/www/html/index.html, and you can create personal web page by modifying this file

# Install Dynamic Web Script(PHP) & Apache Integration Package
sudo apt -y install php
php -v
sudo apt -y install libapache2-mod-php
sudo systemctl restart apache2

# Create PHP file for testing and verifying its operation
sudo vim /var/www/html/info.php
---------------------------------------------------------------------------------------------------------------------------
<?php
echo "Hello, PHP!";
?>
---------------------------------------------------------------------------------------------------------------------------

Successful if PHP information displays correctly after entering `localhost/info.php` in the browser

※ When IP address entered into web browser, it interprets the content stored in the `index.html` file and displays it to the user in the form of text, image, table, link, etc.
※ Therefore, PHP file for testing should be created in the /var/www/html/ directory

# Server Update & Hostname Configuration (Modify [Hostname])
sudo hostnamectl set-hostname [Hostname]
sudo vim /etc/hosts
hostnamectl

# Apache2 systemd Service Configuration
sudo vim /usr/lib/systemd/system/apache2.service

# File Path
Main Configuration File: /etc/apache2/apache2.conf
Default Web Page: /var/www/html/
Web Request Log File: /var/log/apache2/access_log
Error Log File: /var/log/apache2/error_log
