# Preview Generator 앱 설치
Nextcloud 웹 관리자 페이지의 앱(Apps) 메뉴에서 Preview Generator를 검색하여 설치 및 활성화

# 웹 서버 권한(www-data)으로 기존 모든 파일에 대한 미리보기 생성
cd /var/www/html/nextcloud
sudo -u www-data php occ preview:generate-all -v
