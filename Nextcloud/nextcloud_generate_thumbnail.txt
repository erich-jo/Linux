◆ Install Essential Package
sudo apt -y update && sudo apt install ffmpeg -y


◆ Modify Configuration File

# Enable Video Provider
sudo vim /var/www/html/nextcloud/config/config.php
---------------------------------------------------------------------------------------------------------------------------
  'enable_previews' => true,
  'preview_ffmpeg_path' => '/usr/bin/ffmpeg',
  'enabledPreviewProviders' => 
  array (
    0 => 'OC\\Preview\\Movie',
    1 => 'OC\\Preview\\PNG',
    2 => 'OC\\Preview\\JPEG',
    3 => 'OC\\Preview\\GIF',
    4 => 'OC\\Preview\\BMP',
    5 => 'OC\\Preview\\XBitmap',
    6 => 'OC\\Preview\\MarkDown',
    7 => 'OC\\Preview\\MP3',
    8 => 'OC\\Preview\\MP4',
    9 => 'OC\\Preview\\TXT',
  ),
---------------------------------------------------------------------------------------------------------------------------


◆ Apply Thumbnails to Existing Files in Bulk

# Generate Preview for Existing Files Using Web Server Permission(www-data)
cd /var/www/html/nextcloud
sudo -u www-data php occ preview:generate-all -v

# Install Preview Generator App (Option)
Nextcloud Website → Profile in Top Right Corner → Apps → Search 'Preview Generator' → Download and enable
