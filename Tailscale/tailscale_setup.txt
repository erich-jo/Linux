◆ Tailscale Setup

# Device Registration & IP Address Verification
Tailscale Website → Network → Machines

# DNS Setting
Tailscale Website → Network → DNS → Tailnet DNS name
Enable MagicDNS & HTTPS Certificates

# Issue Certificates
Tailscale Website → Settings → Keys → Auth keys → Generate auth key...

※ Since Tailscale domains are exclusive to a closed private network(VPN), it's impossible to obtain certificates using the standard Let's Encrypt(Certbot) HTTP validation method.

# Move Certificates (Modify [File Name])
.crt file: sudo mv [File Name].crt /etc/ssl/certs
.key file: sudo mv [File Name].key /etc/ssl/private


◆ Tailscale Certificate Automatic Reissue/Renewal Setup

1. Write Update Script
sudo vim /usr/local/bin/renew-tailscale-cert.sh
---------------------------------------------------------------------------------------------------------------------------
#!/bin/bash

# Domain Name Setting (Modify [Domain Name] in a form of "Machine_name.Tailnet_DNS_name")
DOMAIN="[Domain Name]"

# Path where certificates will be saved
CERT_DIR="/etc/ssl/certs"
KEY_DIR="/etc/ssl/private"

# Tailscale Certificate Renewal (Issued directly to a specified path)
/usr/bin/tailscale cert --cert-file "${CERT_DIR}/${DOMAIN}.crt" --key-file "${KEY_DIR}/${DOMAIN}.key" "${DOMAIN}"

# Permission Setting (Essential for maintaining private key security)
chmod 644 "${CERT_DIR}/${DOMAIN}.crt"
chmod 600 "${KEY_DIR}/${DOMAIN}.key"

# Reload Apache only if the configuration test is successful
if /usr/sbin/apachectl configtest; then
    /usr/bin/systemctl reload apache2
fi
---------------------------------------------------------------------------------------------------------------------------

2. Grant Script Execution Permissions
sudo chmod +x /usr/local/bin/renew-tailscale-cert.sh

3. Manual Script Testing
sudo /usr/local/bin/renew-tailscale-cert.sh

4. Root Crontab Registration
sudo crontab -e
0 12 1 * * /usr/local/bin/renew-tailscale-cert.sh > /dev/null 2>&1

※ Definition of the first numbers
Minute(0~59) / Hour(0~23) / Day(1~31) / Month(1~12) / Day of the week(0~6, 0=SUN, 6=SAT)
